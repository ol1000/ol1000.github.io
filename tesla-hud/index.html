Car HUD

Set it up while parked. Once started it needs no touching.

Satnav: destination search and routing use public OpenStreetMap services, so your search text and location are sent to them. There is no live traffic and no speed limit data. Pick a destination before you drive; never type while moving.

Mirror flips the display so it reads correctly when the phone lies flat on the dash and reflects in the windshield. Speed comes from GPS, so it needs a clear sky view and location permission. It is a guide only; your car's speedometer is the reference.
